
# Bank Log Analyzer (Python)
A Python program that analyzes bank server log files and generates useful reports about system activity.

## Features
- Failed Login Report
- Query Activity Summary
- Slow Query Detector
- Transaction Report
- Critical Events Report
- User Activity Report
- Session Report
- Events Per Hour Report
- General Log Summary

## Project Files
- `main.py` — Main program and menu.
- `parser.py` — Parses log file entries.
- `log_entry.py` — Defines the log entry structure.
- `reports.py` — Generates analysis reports.
- `bank_server.log` — Sample log file.

## How to Run

Make sure Python 3 is installed.

Run the program:

```bash
python main.py
```

Select a report from the menu.
